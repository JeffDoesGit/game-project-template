# The game's Claude project

The bootstrap fills the placeholders and prints these for pasting. `instructions.md` goes in the Claude project's *Project instructions* field. `chat-work.md` is the first message of the one work chat. `chat-review.md` is the first message of a review chat, only when there are PRs from others. Status briefs come from the brief skill, imported into the project, not from a chat. Upload the token file and (for reference) `GDD.md` to the project's files.
